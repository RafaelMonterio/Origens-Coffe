# ORIGENS --- Cafeteria Artesanal ☕

Projeto fictício de uma cafeteria artesanal desenvolvido para praticar e
demonstrar habilidades de **desenvolvimento Front-end**. O site
apresenta a experiência de uma marca de cafés especiais, com páginas de
loja, assinatura, conteúdo e área do cliente.

> **Aviso:** este é um projeto de estudo. A marca, os produtos e as
> funcionalidades são fictícios. Não é uma loja real e não deve ser
> utilizado para realizar compras verdadeiras.

## ✨ Funcionalidades e páginas

-   **Página inicial:** apresentação visual da marca ORIGENS.
-   **Loja:** vitrine de cafés e acessórios.
-   **Assinatura:** página ilustrativa de planos de assinatura.
-   **Blog e artigos:** conteúdo relacionado ao universo do café.
-   **Cursos:** apresentação de cursos e experiências.
-   **Perfil do cliente:** interface demonstrativa de área pessoal.
-   **Checkout e rastreamento:** páginas de demonstração de etapas de
    compra e acompanhamento de pedido.
-   **Contato:** página com informações e interface de contato.
-   **Animações e interações:** elementos interativos e animações de
    rolagem para enriquecer a navegação.

*As funcionalidades são demonstrativas; recursos que dependem de
servidor, banco de dados, pagamentos ou serviços externos podem não
funcionar como em uma aplicação de produção.*

## 🛠️ Tecnologias utilizadas

-   **HTML5** --- estrutura e organização das páginas.
-   **CSS3** --- estilos, layout e apresentação visual.
-   **JavaScript** --- interações e comportamentos da interface.
-   **Google Fonts** --- tipografia utilizada no projeto.

## 🚀 Como executar

1.  Baixe ou clone este repositório.
2.  Abra a pasta do projeto.
3.  Abra o arquivo `index.html` no navegador.

Para uma experiência de desenvolvimento mais prática, você também pode
abrir a pasta no Visual Studio Code e utilizar a extensão **Live
Server**.

## 🎯 Objetivo

Este projeto foi criado para praticar conceitos de Front-end, como
estruturação de páginas, estilização com CSS, organização de arquivos,
criação de interfaces para diferentes seções de um site e implementação
de interações com JavaScript.
